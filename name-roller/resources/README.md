# 资源目录说明

本目录包含点名器所需的所有资源文件。

## 目录结构

```
resources/
├── video/           # 开场视频资源
│   ├── intro.mp4    # 开场视频文件（使用sfeMovie时）
│   └── frames/      # 帧序列图片（无sfeMovie时使用）
│       ├── 001.png
│       ├── 002.png
│       └── ...
├── characters/      # 角色立绘图片
│   ├── 张三.png
│   ├── 李四.jpg
│   └── ...
├── fonts/           # 字体文件
│   └── default.ttf
└── config/          # 配置文件
    └── names.txt    # 名字列表
```

## 各目录详细说明

### video/ - 开场视频

支持两种视频播放方式：

1. **完整视频文件**（推荐，需要sfeMovie库）
   - 文件名：`intro.mp4`
   - 格式：MP4, AVI, MOV 等常见视频格式
   - 建议分辨率：1280x720 或更低
   - 建议时长：5-15秒

2. **帧序列动画**（兼容性更好，无需额外库）
   - 目录：`frames/`
   - 将视频的每一帧导出为图片
   - 文件名按顺序编号：`001.png`, `002.png`, `003.png`...
   - 格式：PNG, JPG 等图片格式
   - 默认按30fps播放
   - 可以使用 FFmpeg 导出帧序列：
     ```bash
     ffmpeg -i intro.mp4 -vf fps=30 frames/%03d.png
     ```

### characters/ - 角色立绘

- 每个名字对应一张立绘图片
- 文件名（不含扩展名）必须与名字完全一致
- 支持格式：PNG（推荐，支持透明背景）、JPG、BMP
- 建议尺寸：高度 500-800 像素
- 建议使用透明背景的 PNG 图片，效果更好

**示例：**
- 名字：`张三` → 立绘文件：`张三.png`
- 名字：`李四` → 立绘文件：`李四.jpg`

> 💡 提示：如果某个名字没有对应的立绘，程序会自动显示默认占位图，不会报错。

### fonts/ - 字体文件

- 放置 TrueType 或 OpenType 字体文件
- 支持格式：`.ttf`, `.otf`
- 第一个加载的字体会作为默认字体
- 可以放置多个字体文件
- 推荐使用中文字体以正确显示中文名字

**推荐字体：**
- 思源黑体（Source Han Sans）
- 微软雅黑
- 文泉驿微米黑
- 阿里巴巴普惠体

### config/ - 配置文件

#### names.txt - 名字列表

- 每行一个名字
- 以 `#` 开头的行为注释
- 空行会被忽略
- 名字前后的空格会被自动去除

**示例：**
```
# 这是注释
张三
李四
王五
```

## 替换资源的方法

### 1. 替换名字列表

1. 打开 `resources/config/names.txt`
2. 按格式添加或修改名字
3. 保存文件即可，无需重新编译

### 2. 添加/替换立绘图片

1. 将立绘图片放入 `resources/characters/` 目录
2. 确保文件名（不含扩展名）与名字完全一致
3. 支持 PNG、JPG、BMP 格式
4. 重新运行程序即可生效

### 3. 替换开场视频

**方式一：使用视频文件（需要sfeMovie）**
1. 将视频文件重命名为 `intro.mp4`
2. 放入 `resources/video/` 目录
3. 重新运行程序

**方式二：使用帧序列（无需额外库）**
1. 将视频导出为帧序列图片
2. 放入 `resources/video/frames/` 目录
3. 确保文件名按顺序编号
4. 重新运行程序

### 4. 替换字体

1. 将字体文件放入 `resources/fonts/` 目录
2. 可以删除或保留原有字体
3. 程序会自动加载目录中的字体
4. 第一个加载的字体会作为默认字体

## 注意事项

1. 所有资源文件路径都是相对于可执行文件的
2. 资源文件修改后无需重新编译，重启程序即可生效
3. 立绘图片建议使用 PNG 格式以获得最佳显示效果
4. 视频分辨率不宜过高，以免影响性能
5. 名字列表中不要有重复的名字
