# 字体目录

请将字体文件放在此目录下。

## 支持的格式

- TrueType (.ttf) - 推荐
- OpenType (.otf)

## 使用规则

- 程序会自动加载此目录下的所有字体文件
- 第一个加载的字体会作为默认字体
- 文件名不影响使用

## 推荐中文字体

1. **思源黑体 (Source Han Sans)** - 开源，免费商用
2. **阿里巴巴普惠体** - 免费商用
3. **文泉驿微米黑** - 开源
4. **微软雅黑** - Windows 系统自带
5. **苹方** - macOS 系统自带

## 注意事项

- 请确保使用的字体有中文支持，否则中文会显示为方框
- 建议使用至少一种中文字体
- 字体文件不要太大，以免影响启动速度

## 示例

```
fonts/
├── SourceHanSansCN-Regular.otf
└── msyh.ttc
```
