# ========================================
# 随机点名器 - 名字列表配置文件
# ========================================
# 
# 使用说明：
# 1. 每行一个名字
# 2. 以 # 开头的行为注释，会被忽略
# 3. 空行会被忽略
# 4. 名字前后的空格会被自动去除
#
# 立绘对应规则：
# - 立绘图片放在 resources/characters/ 目录下
# - 图片文件名（不含扩展名）需要与名字完全一致
# - 例如：名字为"张三"，则立绘图片应为"张三.png"或"张三.jpg"
# - 支持的图片格式：png, jpg, jpeg, bmp
# - 如果找不到对应立绘，会显示默认占位图
#
# ========================================
