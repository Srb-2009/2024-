# 开场视频目录

请将开场视频资源放在此目录下。

## 两种视频方案

### 方案一：完整视频文件（推荐，需要 sfeMovie 库）

将视频文件命名为 `intro.mp4` 放在此目录下。

**支持格式：** MP4, AVI, MOV, MKV 等常见视频格式

**建议规格：**
- 分辨率：1280x720 或更低
- 时长：5-15 秒
- 编码：H.264

**示例：**
```
video/
└── intro.mp4
```

### 方案二：帧序列动画（兼容性更好，无需额外库）

如果没有安装 sfeMovie，程序会自动使用帧序列方案。

将视频的每一帧导出为图片，放在 `frames/` 目录下。

**导出方法（使用 FFmpeg）：**
```bash
# 导出为 30fps 的 PNG 帧序列
ffmpeg -i intro.mp4 -vf fps=30 frames/%03d.png
```

**命名规则：**
- 按播放顺序编号
- 建议使用三位数编号：001.png, 002.png, 003.png...
- 程序会按文件名排序播放

**示例：**
```
video/
└── frames/
    ├── 001.png
    ├── 002.png
    ├── 003.png
    └── ...
```

## 注意事项

1. 如果同时存在视频文件和帧序列，优先使用视频文件
2. 帧序列默认按 30fps 播放
3. 视频分辨率不宜过高，以免影响性能
4. 开场动画可以按空格键跳过
5. 如果没有任何视频资源，程序会直接进入准备状态
