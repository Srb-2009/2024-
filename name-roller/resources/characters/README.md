# 角色立绘目录

请将角色立绘图片放在此目录下。

## 命名规则

- 文件名（不含扩展名）必须与名字完全一致
- 例如：名字为"张三"，则立绘文件应为"张三.png"

## 支持的格式

- PNG（推荐，支持透明背景）
- JPG / JPEG
- BMP

## 建议规格

- 高度：500-800 像素
- 背景：建议使用透明背景（PNG格式）
- 风格：统一风格效果更佳

## 示例

```
characters/
├── 张三.png
├── 李四.jpg
├── 王五.png
└── 赵六.png
```

> 💡 如果某个名字没有对应的立绘，程序会自动显示默认占位图，不会报错。
